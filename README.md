# La Hipérbola — Grupo 4

Presentación web de Geometría Analítica sobre la hipérbola, para Grupo 4.

## Cómo abrirla

Doble clic en `index.html`. Se abre en el navegador y ya funciona.

No necesita internet, salvo las tipografías (Orbitron, Inter, STIX). Si abres el archivo
sin internet, el texto se ve con una tipografía genérica pero la presentación es legible.

## Contenido

1. Portada — HIPÉRBOLA, Grupo 4, integrantes
2. Definición — qué es una hipérbola y demostración animada de la diferencia constante
3. Fórmula general — `(x-h)²/a² - (y-k)²/b² = 1` con la gráfica
4. Espacio reservado para el Kahoot

## Cómo navegar

- Flechas del teclado `↑` `↓`, o `Espacio` y `Enter`
- Rueda del ratón
- Deslizar en pantalla táctil
- Botones abajo a la izquierda, o los números `01` a `04` abajo a la derecha
- Las teclas `1` a `4` saltan directo a una diapositiva
